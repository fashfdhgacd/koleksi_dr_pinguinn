# Audit SEO — 4 November 2026

## A. Kondisi saat ini dan batas audit

Audit parsial ini meninjau routing, katalog, metadata, middleware, cache dan workflow terkait SEO
pada `fac5712`, preview lokal, dan log GitHub Actions yang sudah ada; bukan pembacaan menyeluruh
seluruh repository, audit seluruh URL produksi, atau verifikasi Search Console. Situs menggunakan TanStack
Start/React, Nitro dan Cloudflare Workers, dengan katalog lokal serta enrichment opsional. Ada
cache HTML, aset dan sitemap; data statistik/owner juga memakai penyimpanan Cloudflare. Tidak ada
perubahan pada database, moderasi, data video, URL publik, atau konfigurasi produksi.

`public/robots.txt` mengizinkan crawler umum, Google dan Bing, menyertakan sitemap, dan membatasi
sebagian bot lain; tidak ada aturan khusus Brave atau Yandex, sehingga keduanya mengikuti `*`
menurut konfigurasi tersebut. Akses sebenarnya masih perlu diuji di Cloudflare. Sitemap dinamis
dipecah menjadi indeks, halaman dan chunk video; cache edge-nya satu jam. Route video dan kategori
memiliki canonical, metadata sosial dan breadcrumb. Pencarian bebas berada di `/?q=...` dengan
`noindex`; `/cari/<slug>` adalah landing terkurasi dengan ambang konten. `/cari` sendiri
mengembalikan 404 di preview, bukan form pencarian.

Resolusi DNS dari lingkungan audit gagal, sehingga tidak dapat menguji situs publik secara
langsung. Log job Site health 4 November 2026 pukul 07:19 UTC mencatat HTTP 200 pada beranda,
`/kategori`, indeks sitemap, 11 sitemap video dan 10 sampel video, serta 10.109 URL video di
sitemap saat itu. Itu adalah bukti historis, bukan jaminan kondisi saat ini atau indeksasi.

## C. Perubahan

- `src/lib/seo.ts`: sebelumnya tanggal yang tidak tersedia diganti tanggal dari hash ID; sekarang
  hanya tanggal katalog yang lolos validasi yang disertakan. URL, title, thumbnail, breadcrumb,
  video, dan perilaku indexing tidak diubah. Ini memengaruhi output markup pada halaman dengan
  tanggal kosong/tidak valid, tetapi tidak mengubah data katalog.
- `scripts/seo-video.test.mjs` dan `package.json`: tes regresi untuk tanggal hilang, tidak valid,
  tanggal mendatang, dan tanggal valid dalam berbagai format; tes dimasukkan ke `npm test`.
- Laporan ini mendokumentasikan temuan dan risiko. Tidak ada penambahan request Worker.

## D. Pengujian

- Build Cloudflare `env -u DATABASE_URL npm run build`: berhasil; migrasi database dilewati.
  Build preview Node terpisah juga berhasil.
- `npm test`: 253 lulus, termasuk dua tes baru. `git diff --check` berhasil. Lint tes baru
  berhasil; lint file SEO dan typecheck memiliki masalah baseline seperti di atas.
- Preview lokal: `/`, `/kategori`, `/robots.txt`, `/sitemap.xml`, `/sitemap-pages.xml`, dan
  sampel `/watch/...` mengembalikan 200; video tidak dikenal dan `/cari` mengembalikan 404.
  Pencarian `/?q=contoh` mengembalikan 200 dengan header `X-Robots-Tag: noindex, follow`.
- Semua 11 dokumen sitemap preview berhasil diparse sebagai XML, dengan 9.824 URL dan tidak ada
  duplikasi `loc`. Jumlah ini untuk preview lokal, bukan angka produksi. Canonical beranda,
  pencarian, kategori, halaman kategori kedua dan satu video diperiksa; satu video menghasilkan
  `VideoObject` tanpa tanggal rekaan dan `BreadcrumbList`. Ini bukan pemeriksaan setiap URL atau
  validasi skema oleh Google.
- Preview pada lebar 375 px untuk beranda dan satu video memiliki lebar dokumen 375 px; ini
  pemeriksaan terbatas, bukan audit mobile penuh. Browser preview memblokir gambar eksternal dan
  `/api/likes-live` mengembalikan 503 pada lingkungan lokal tanpa binding produksi.
- Waktu respons dan hasil mobile lokal bukan Core Web Vitals atau pengukuran biaya/CPU Cloudflare.

## E. Belum dapat diverifikasi

Status ditemukan, di-crawl, diindeks, dan muncul di hasil pencarian adalah empat hal berbeda.
Keempatnya belum diverifikasi. CTR, posisi, trafik organik, penerimaan sitemap, IndexNow, akses
crawler Brave/Yandex, CWV lapangan, serta request/CPU/database produksi juga belum diverifikasi.
Tidak ada klaim peningkatan ranking atau trafik.

## F. Langkah berikutnya

1. Review perubahan dan dampak kehilangan kelayakan rich result untuk tanggal yang belum diketahui;
   pasok tanggal unggah yang benar hanya jika sumbernya dapat dipercaya.
2. Sediakan akses baca Search Console, Bing Webmaster Tools, Yandex Webmaster, dan metrik Cloudflare;
   periksa sitemap, crawl, indexing, CWV serta halaman ber-impression tinggi secara terukur.
3. Audit `lastmod`, IndexNow dan thumbnail dengan data produksi sebelum merencanakan perubahan
   berikutnya; verifikasi aturan dan endpoint langsung melalui dokumentasi resmi masing-masing.
4. Setelah review dan persetujuan eksplisit, barulah rencanakan deployment dan verifikasi live.
